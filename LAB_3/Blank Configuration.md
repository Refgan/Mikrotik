## LAB 3 BLANK CONFIGURATION

*Blank Configuration* adalah kondisi di mana router MikroTik dikembalikan atau disetel dalam keadaan bersih tanpa adanya konfigurasi bawaan pabrik (default configuration).

Saat pertama kali membeli MikroTik baru, biasanya sudah terpasang konfigurasi default (seperti IP 192.168.88.1 pada ether1/ether2, aturan firewall dasar, dan DHCP server).
Memilih Blank Configuration berarti Anda menghapus semuanya dan memulai konfigurasi router dari titik nol (halaman kosong).
